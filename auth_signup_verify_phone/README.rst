Installation
============

* Install `phonenumbers <https://pypi.org/project/phonenumbers/>`_
  with ``pip install phonenumbers`` or equivalent.

Configuration
=============

To configure this module, you need to:

* Update the ISO code in *Settings > Translations > Languages* to match the ISO-639-1.

Usage
=====

To use this module, you need to:

* Log out.
* `Sign up </web/signup>`_ with a valid phone.
